# Kaggle: start here

1. Push this repository to GitHub.
2. Open `notebooks/Kaggle_End_to_End_Run.ipynb` in Kaggle.
3. Replace `YOUR_GITHUB_REPO_URL`.
4. Run cells from top to bottom.
5. The notebook downloads the official H&M competition data using `kagglehub`.
6. It automatically sets `HM_DATA_DIR`, so no manual dataset path is required.
7. Final outputs are in `results/`.

Do not upload or load the `images/` directory.
